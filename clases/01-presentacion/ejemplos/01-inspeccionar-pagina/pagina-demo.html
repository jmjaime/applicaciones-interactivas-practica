Aplicaciones Interactivas — UADE

Esta página carga estilos, JavaScript e imágenes desde varios dominios distintos. Abrila con las DevTools abiertas (F12) y mirá:

  • Network: en qué orden salen los requests y cuáles van en paralelo
  • Elements: cómo quedó el DOM (comparado con "Ver código fuente")
  • Styles / Computed: qué reglas del CSSOM aplican a cada elemento

Temas de la clase

    🎨 Colores del waterfall en Network (para entender los requests de arriba)
    ColorFaseQué significa
    Gris claroQueueingEl browser encola el request (ya hay 6 conexiones abiertas al mismo host, o hay requests de mayor prioridad)
    Gris oscuroStalledFrenado ya con la conexión abierta, por las mismas razones que Queueing
    CyanDNS LookupResolviendo el dominio a una IP
    NaranjaInitial connectionHandshake TCP (y a veces la negociación SSL)
    VioletaSSLNegociación TLS/SSL (HTTPS)
    VerdeRequest sentEl browser mandó el request — franja fina
    Verde-amarillentoWaiting (TTFB)Esperando el primer byte de respuesta del servidor
    AzulContent DownloadDescargando el body de la respuesta

    Dos líneas verticales cruzan todo el waterfall: azul = evento DOMContentLoaded, roja = evento load.

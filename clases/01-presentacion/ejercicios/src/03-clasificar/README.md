# 03 — Clasificar número

**Tema:** condicionales (`if` / `else if` / `else`).

## Consigna

Completar `clasificar.ts`: recibe un número y debe devolver `"negativo"`, `"cero"` o
`"positivo"` según corresponda.

```ts
clasificarNumero(-5); // "negativo"
clasificarNumero(0);  // "cero"
clasificarNumero(7);  // "positivo"
```

## Cómo validar

```bash
npm test -- 03-clasificar
```

#### Ejercicio 2.1: Arreglar el lint

**Objetivo**: practicar la lectura de errores de ESLint y su corrección
(visto en el Bloque 2 de la clase).

**Requisitos**:

- [ ] `npm run lint` no reporta errores en `exercise.ts`.
- [ ] `calcularDescuento` y `formatearRespuesta` siguen devolviendo
      exactamente lo mismo que antes de arreglar el lint (no es un
      ejercicio de lógica, es de estilo/tipos).

No tiene test automático — se valida corriendo `npm run lint`, no
`npm test`.
